# Спрайт-редактор (`pixel-editor.html`)

Піксельна графіка й анімація для ігор. Одна сторінка, без збирання; дані лишаються в браузері.

## Що вміє

**Малювання.** Олівець, гумка, заливка, піпетка, лінія, прямокутник, коло, виділення, ласо, чарівна паличка, дизеринг, градієнт, світліше/темніше. Піксель-перфект, круглий пензель, дзеркало по двох осях, заміна кольору в усьому спрайті.

**Кольори.** Палітри, рампа з 7 відтінків (тіні холодніші, світла теплішіші), імпорт палітр (`.hex`, `.gpl`, JASC `.pal`, список кодів із Lospec), палітра з кольорів спрайту, еталонна картинка під полотном (прозорість, розмір, зсув).

**Шари.** Видимість, прозорість, блокування, порядок (перетягування або меню), об'єднання, дублювання. Alt+клік по оку показує лише цей шар.

**Анімація.** Кадри, тривалість кожного кадру в мс, теги (підписані діапазони), порядок вперед / назад / туди-назад, калька з налаштуваннями, плитка 3×3 з переносом мазків через край.

**Експорт.** PNG, аркуш кадрів (з відступом і JSON), послідовність PNG у `.zip`, GIF з тривалістю кожного кадру, код для гри. Експортувати можна всі кадри або тільки один тег.

**Імпорт.** Картинка в кадр або новий кадр, нарізання аркуша кадрів за сіткою на новий спрайт, вставка картинки з буфера (Ctrl+V), перетягування файлу на сторінку, відновлення з файлу копії `.json`.

**Надійність.** Автозбереження, скасування до 120 кроків, копія файлом, якщо у браузері закінчилося місце, копія всіх спрайтів одним файлом.

## Вкладки правої панелі

| Вкладка | Вміст |
|---|---|
| Колір | палітра, імпорт, кольори спрайту |
| Шари | список шарів, прозорість |
| Анімація | кадри на секунду, тривалість кадру, порядок, теги |
| Полотно | розмір, сітка, фон, перетворення, калька, плитка, еталон |

Угорі панелі завжди видно поточний колір із рампою та перегляд анімації.

## Формат збереження

Ключ `localStorage`: `edvault-sprites`, масив записів. Кадри стиснуті в рядки: один символ на піксель, `0` — прозорий, інші символи — індекс у `palette`.

- `v: 2` — один звичайний шар: `{ palette, frames: [рядок] }`.
- `v: 3` — кілька шарів: `{ palette, layers: [{ name, visible, locked, opacity, frames }], active }`.
- `anim` (необов'язково): `{ durs: [мс або 0], tags: [{ id, name, from, to, dir }], dir }`, де `dir` — `fwd`, `rev` або `pp`.
- Старі записи без `anim` і з масивами пікселів відкриваються як є.

Інші ключі: `edvault-sprite-palettes` (імпортовані палітри), `edvault-sprite-colors` (мої кольори), `edvault-sprite-view` (калька, фон полотна, крок сітки), `edvault-sprite-tab` (вкладка панелі), `edvault-theme` (тема).

Файл копії — звичайний JSON запису (один спрайт) або `{ app, version, sprites: [...] }` (всі).

## Тести

```sh
node tests/sprite-e2e.mjs           # інструменти малювання й виділення
node tests/sprite-layers-e2e.mjs    # шари
node tests/sprite-colors-e2e.mjs    # рампа, палітри, еталон
node tests/sprite-anim-e2e.mjs      # тривалість, теги, експорт, імпорт аркуша, копія
node tests/sprite-extras-e2e.mjs    # блокування, соло, плитка, буфер, копії, пошкоджені записи
node tests/sprite-layout-e2e.mjs    # розкладка на настільних розмірах вікна
```

Усі браузерні тести запускає `npm run test:e2e -- sprite`.

## Розкладка

Працює на настільних екранах від 1280×720 до 2560×1440. Мобільної версії немає: нижче 900 px панелі складаються в стовпець без турботи про дотик.
