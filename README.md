# Інструменти для вчителя й учнів

Дванадцять інструментів, які працюють просто в браузері: без встановлення, без реєстрації й без сервера. Статичні сторінки: HTML, CSS і модулі JavaScript, нічого не треба збирати.

| Сторінка | Що це |
|---|---|
| `whiteboard.html` | Вайтборд: олівець, фігури, стікери, лазерна указка, PDF і режим презентації |
| `vote.html` | Голосування за кращу роботу з підрахунком наживо |
| `class-manager.html` | Менеджер класу: учні, розклад, відвідуваність і оцінки |
| `screen-recorder.html` | Запис екрана з мікрофоном і веб-камерою, MP4 або WebM |
| `videocut.html` | Відеоредактор: різання, текст, субтитри, музика, експорт у MP4 |
| `snap-editor.html` | Редактор фото й скриншотів: стрілки, текст, розмиття, кроки |
| `image-convert.html` | Конвертер зображень: JPG, PNG, WebP, AVIF, SVG, ICO |
| `text-craft.html` | Текстовий редактор з блоками, шаблонами й експортом |
| `web-editor.html` | Редактор коду HTML, CSS і JavaScript з живим переглядом |
| `color-tool.html` | Кольори: палітри, гармонії й перевірка контрасту |
| `pixel-editor.html` | Спрайт-редактор: піксельна графіка й анімація |
| `animator.html` | Аніматор: мультфільми кадр за кадром, експорт у відео чи GIF |

## Запуск

```sh
npm start            # http://localhost:8080
npm test             # модульні тести
npm run test:e2e     # тести в браузері (потрібен Playwright)
```

## GitHub Pages

Settings → Pages → Deploy from a branch → `main`, `/ (root)`. Усі шляхи відносні, тож сайт працює й у підпапці.

Дані зберігаються лише в браузері (localStorage, IndexedDB) і у файлах, які людина зберігає сама.
